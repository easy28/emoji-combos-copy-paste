# emoji-combos-copy-paste

Copy-paste emoji combos for bios, captions and gaming profiles (aesthetic / love / gaming / holiday / sports / food / moody / dreamy). Live at <https://easy28.github.io/emoji-combos-copy-paste/>.

Combo sets link to the similar emoji finder on [emojimagic.io](https://emojimagic.io/similar-emoji) — paste any emoji, get 100+ ranked lookalike combos.
